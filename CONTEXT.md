# ПроВожатый — сайт (лендинг)

Сервис безопасного сопровождения детей в школу и на кружки (Москва, 1–4 класс). Проверенный сопровождающий (часто старшеклассник из той же школы) забирает ребёнка, ведёт по маршруту, родитель видит путь онлайн и получает подтверждение «дошёл».

Проект — независимая песочница. Прод (go.provozhaty.ru) не трогаем.

## Структура

- `landing/` — Фаза 1: рабочий лендинг (чистый HTML/CSS/JS + GSAP ScrollTrigger, 8 экранов)
- `references/design-system.md` — дизайн-система, извлечённая из инвесторской презентации
- `docs/agents/issue-tracker.md` — конвенция локального трекера задач
- `docs/adr/` — архитектурные решения
- `.scratch/<feature-slug>/` — спеки и тикеты текущих автопилот-заходов

## Фазы

1. ✅ Базовый лендинг (структура, дизайн-система, hero-анимация, форма)
2. ✅ Несколько принципиально разных визуальных вариантов с переключением. Тема Б («Мягкий и воздушный») выбрана пользователем и сделана дефолтной.
3. ✅ Полировка через impeccable (контраст текста, иконки вместо эмодзи, фокус-состояния, единый авторский момент анимации — прорисовка диаграммы доверия)
4. ⛔ Генерация фото/видео через higgsfield-generate — не нужна: пользователь предоставил готовое hero-видео (флэт-иллюстрация), оно уже встроено на этапе Фазы 1 и полировалось в Фазе 3
5. ⛔ Панель твиков (цвета/шрифты/анимации на лету) — не нужна: пользователя устраивает текущий дизайн (тема Б), решено не давать себе лишний рычаг для расшатывания уже утверждённого вида

## Статус: лендинг готов

Все актуальные фазы закрыты. Дефолтный вид — тема Б («Мягкий и воздушный»), переключатель А/Б/В остаётся для сравнения. Открытые темы на будущее (не блокируют текущий результат): реальный текст политики конфиденциальности (сейчас заглушка `#privacy`), приём формы на бэкенде (сейчас JS-заглушка), деплой на реальный домен.

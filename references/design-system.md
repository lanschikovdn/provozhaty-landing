# Дизайн-система «ПроВожатый»

Извлечено из инвесторской презентации (`ProVozhatyi_Investor_Deck_2026_v2.pdf`, 12 слайдов) и встроено под лого (два персонажа — взрослый и ребёнок со школьными рюкзаками, держатся за руки).

## 1. Палитра

Два режима секций — светлый и тёмный, чередуются по странице. Один и тот же зелёный работает акцентом в обоих.

| Токен | HEX | Где используется |
|---|---|---|
| `--cream` | `#F5F4EF` | фон светлых секций |
| `--cream-card` | `#FFFFFF` | карточки на светлом фоне |
| `--navy` | `#14121F` | фон тёмных секций |
| `--navy-card` | `#1B1930` | карточки на тёмном фоне (чуть светлее фона) |
| `--ink` | `#17162A` | текст-заголовки на светлом фоне |
| `--ink-muted` | `#5B5A66` | вспомогательный текст на светлом фоне |
| `--paper` | `#F5F4EF` | текст-заголовки на тёмном фоне (кремовый, не чистый белый) |
| `--paper-muted` | `#A6A4B3` | вспомогательный текст на тёмном фоне |
| `--forest` | `#0E6C50` | акцентный зелёный на светлом фоне (заголовки-выделения, кнопки, cards-highlight) |
| `--forest-deep` | `#0B5A42` | тёмно-зелёные акцентные карточки/плашки |
| `--mint` | `#7EE2B8` | акцентный зелёный на тёмном фоне (выделения в заголовках, крупные цифры, ссылки) |
| `--mint-pale` | `#E1F0EB` | подложки пилюль-бейджей на светлом фоне |

Правило: зелёный (`forest` / `mint`) — единственный цветной акцент. Никаких дополнительных цветов (синего, жёлтого и т.п.) не вводить.

## 2. Типографика

- **Заголовки (display/h1-h3):** жирный сериф с крупным x-height, слегка «книжный» — референс: **PT Serif** (`font-weight: 700`), запасной — Georgia. Кегль h1 — очень крупный (72–96px на десктопе), плотный line-height (1.05–1.1), возможен частичный акцент зелёным цветом внутри одного заголовка (не весь текст).
- **Текст/UI (body, лейблы, кнопки, форма):** чистый гротеск без засечек — референс: **Inter** (400/500/600/700). Лейблы-эйбраны (ЗАКРЫТОЕ СООБЩЕСТВО, ПРОБЛЕМА и т.п.) — uppercase, letter-spacing +0.08em, мелкий кегль (12–13px), полужирный.
- **Крупные цифры-статистика:** тот же сериф, что и заголовки, очень крупный кегль (56–96px), зелёным или mint-цветом.

Подключение: Google Fonts `PT Serif` + `Inter`, с `font-display: swap`.

## 3. Сетка и отступы

- Контентная колонка: `max-width: 1200px`, поля по бокам — не менее 64px на десктопе, 20px на мобильном.
- Секция = полноширинный блок с фоном (cream или navy), внутри — контентная колонка.
- Вертикальный ритм секции: паддинг сверху/снизу 96–140px на десктопе, 56–72px на мобильном.
- Карточки: скругление `20–24px`, внутренний паддинг `32–40px`, мягкая тень только на светлом фоне (`0 20px 40px rgba(20,18,31,0.06)`), на тёмном фоне карточки без тени — только контраст фона.
- Пилюли-бейджи: скругление `999px`, паддинг `8px 18px`.
- Сетки карточек: 2 или 4 колонки на десктопе → 1 колонка на мобильном, gap 20–24px.

## 4. Ритм секций (чередование)

Ни одна секция не повторяет визуальный приём соседней:

1. Hero — светлый фон, текст слева / визуал справа (или во всю ширину под скролл)
2. Тёмная секция со статистикой — контраст «светлая карточка vs тёмная карточка» рядом
3. Светлая секция — центральная диаграмма/схема (треугольник, окружность-хаб)
4. Светлая секция — горизонтальный ряд пронумерованных карточек (01–05) + телефон-мокапы
5. Тёмная секция — вертикальный список с иконками-галочками, одна ячейка выделена зелёным
6. Светлая/акцентная — две развилки-карточки рядом (симметрия)
7. Тёмная акцентная секция — финальный CTA, крупная форма
8. Футер — минималистичный, тёмный, мелкий текст

## 5. Компоненты, встреченные в референсе

- Пилюля-бейдж (маленький лейбл в скруглённой подложке)
- Карточка-статус (крупное число + подпись)
- Карточка с чекмарком (✓ в круглой подложке + жирный заголовок + серый текст)
- Тёмная «выделенная» карточка внутри списка обычных (акцент через насыщенный зелёный фон)
- Телефон-мокап (скруглённый прямоугольник с чёрной рамкой, внутри — скриншот интерфейса)
- Плашка-цитата (вертикальная зелёная полоса слева + текст)
- Диаграмма-хаб (круг по центру, карточки-спицы вокруг, стрелки между ними)
- Всплывающая подсказка-бейдж поверх иллюстрации (белая карточка с точкой-статусом, как на hero)

## 6. Логотип

`landing/assets/logo-full.jpg` — полный логотип (иллюстрация + вордмарк «ПроВожатый», где «Про» — тёмно-синий, «Вожатый» — зелёный).
`landing/assets/mark.jpg` — только иллюстрация (взрослый + ребёнок, зелёная форма), используется как знак в шапке рядом с текстовым логотипом.

Иллюстративный стиль: плоский флэт-дизайн, чёрный контур средней толщины, заливка — зелёные и телесные тона, скруглённые формы без острых углов. Этот же стиль — основа для покадровой SVG-сцены в hero.
